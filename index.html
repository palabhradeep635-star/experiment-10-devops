Experiment Objective

Understand the practical implementation of a cloud-based DevOps pipeline.

The objective of this experiment is to understand and implement a Continuous Integration and Continuous Deployment (CI/CD) pipeline using cloud services. The workflow connects source control with automated build, validation, and deployment steps. This helps reduce manual effort and improves the speed, consistency, and reliability of software delivery.

Technology Stack

Core tools that bring source control, automation, and cloud hosting together.

☁

Cloud Platform

A cloud hosting service such as Azure Static Web Apps or an appropriate AWS service provides the environment for publishing the application.

⌘

GitHub Repository

GitHub stores the source code and tracks changes. A push or commit can trigger a configured deployment workflow.

⚙

CI/CD Automation

An automated workflow builds the project, runs configured checks, and deploys updates with less repetitive manual work.

CI/CD Workflow

A four-stage view of the automated application delivery lifecycle.

01

Code

Create or update the web application and commit changes to the source repository.

02

Build

The configured workflow retrieves the source code and prepares the application for publishing.

03

Validate

Configured checks or tests run so issues can be identified before the release is completed.

04

Deploy

The deployment service publishes the application and provides a URL for verification.

Implementation Procedure

A practical sequence for configuring and verifying a cloud deployment pipeline.

01

Prepare the application

Create a basic static web application using HTML, CSS, and JavaScript. Test the files locally before deployment.

02

Create or update the GitHub repository

Upload the source files to GitHub and make sure the repository contains the correct entry page and required assets.

03

Configure cloud hosting

Create the hosting resource in the selected cloud platform and connect it to the source repository where supported.

04

Configure the CI/CD workflow

Set the relevant build settings, deployment branch, and workflow configuration according to the chosen cloud service.

05

Run and inspect the pipeline

Push a small update and inspect the workflow logs to check whether the configured steps completed successfully.

06

Verify the deployed website

Open the deployment URL, confirm that the page loads correctly, and check that the latest changes are reflected.
